# VisionAI - Real-Time Object Detection

VisionAI is a real-time object detection system built using Python, Flask, YOLO and OpenCV.

## Features

- Real-time object detection
- Live webcam feed
- Object counting
- FPS display
- Detection confidence
- Detection history
- Capture screenshot
- Clear detection history

## Technologies Used

- Python
- Flask
- YOLO
- OpenCV
- HTML
- CSS
- JavaScript

python app.py
